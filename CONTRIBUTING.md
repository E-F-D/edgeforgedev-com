# Contributing to EdgeForgeDev

Thank you for considering a contribution! This project is in early stages — most issues, PRs and discussions are welcome.

## Code of Conduct

Be respectful. We follow a [Contributor Covenant](https://www.contributor-covenant.org/) approach.

## How to Contribute

1. **Bug reports**: Open a GitHub issue with reproduction steps + environment.
2. **Feature requests**: Open a GitHub issue with use case + expected behavior.
3. **Pull requests**:
   - Fork the repo
   - Create a feature branch (`git checkout -b feature/awesome`)
   - Commit with conventional commits format (`feat:`, `fix:`, `docs:`, etc.)
   - Push and open a PR

## Security Issues

**Do not** open public GitHub issues for security vulnerabilities.
Email: `security@edgeforgedev.com`
